明道中医 问诊台
给中医师用的智能问诊工作台

面向中医门诊的垂域智能体外壳：问诊对话与辨证知识交给 Dify（RAG）， 患者识别、病历落盘、复诊对比、回访追踪由本地内核强制。 中西医术语不做改写，判断权始终归属执业医师。

病历号制患者主键 · 主诉/现病史必填 · 缺项绝不编造 · 不输出诊疗结论（内核红线，非提示词劝告）· 患者数据本地化，不入库、不出内网。

● 下载桌面版

内置内核与问诊台的一次性安装包：双击即用、无需终端。安装后首次启动会引导填入模型与 Dify 的密钥 （密钥只存在本机 MINGDAO_HOME，不上传）。本页安装包由本站在内网提供，不依赖 GitHub 下载。

● 它为中医门诊做了什么

不做通用助手，只做中医垂域那一层 —— 每个能力都在内核的同一条链路里（权限 / 审计 / 计费 / 约束）。

🗂病历号制患者主键

姓名同名在门诊极常见，用姓名当主键会混病历。这里主键是病历号，姓名 + 出生年 + 性别只是收窄条件； 同名多命中时返回候选请医师确认，绝不替你挑一个。

📋门诊病历结构

主诉、现病史为必填；既往史 / 家族史 / 过敏史 / 流行病史 / 体格检查 / 舌象 / 脉象 / 随访可选。 舌象与脉象单独留字段 —— 此前无处可放，医师写下的舌脉会被直接丢掉。

🔁复诊四态对比

消失 / 减轻 / 无变化 / 加重，逐项列出。只陈述事实，不作疗效结论 —— 对比表是用来给医师判断的，不是替代判断。

📞回访看板与超期预警

按超期优先排列的名册，临期提前提醒；单患者时间线、异常预警与随访话术草稿（草稿标注「需医师确认」）。

🚧红线由内核强制

缺项绝不编造、不输出诊疗结论、不得跨患者串病历 —— 这三条是内核约束，不是提示词里的一句劝告； 命中会进审计，可回溯「哪条红线、在什么时候被触发」。

💰费用与审计

每一次域内模型调用都计入归因（cost --by pack 可查），长任务期间今日费用实时累计。

● 数据与合规

患者数据本地化

  • 患者注册表与病历快照存在本机 MINGDAO_HOME，不入 git、不上传；
  • 写入用原子写（临时文件 + rename），崩溃不留半份病历；
  • 半份病历刻意不落盘 —— 它会被下次复诊当成基线，比没有更危险；
  • 注册表损坏时大声失败，绝不降级成空注册表（发错病历号不可逆）。

定位与边界

  • 本产品为知识工作助手，不输出诊疗建议、不下诊断；
  • 临床使用须遵守《个人信息保护法》及互联网诊疗相关规定；
  • 判断权始终归属执业医师；
  • 问答与辨证知识来自医师所在机构自有的 Dify 工作流与知识库。

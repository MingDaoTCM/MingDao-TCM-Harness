使用帮助

从安装到第一次问诊，大约 5 分钟。全部操作在桌面版应用内完成，不需要命令行。

① 安装 ② 填密钥 ③ 问诊 ④ 患者与随访 ⑤ 更新与反馈 常见问题

①安装

在下载页按你的系统选一个安装包：

系统文件说明
Windows 10/11mingdao-tcm-setup-…-x64.exe双击安装，从开始菜单启动。首次运行若出现 SmartScreen 提示，点「更多信息 → 仍要运行」。
macOS（Apple 芯片）mingdao-tcm-…-arm64.dmg已签名并公证，双击打开即可。
macOS（Intel）mingdao-tcm-…-x64.dmg同上。
Linux.deb / .AppImagedeb 用 sudo dpkg -i；AppImage 先 chmod +x 再双击。

安装包里不含任何密钥。密钥由你自己填，只写在你本机的数据目录里，不上传、不进安装包 —— 这也是每个人用自己那把密钥的原因。

②第一次启动：填密钥

打开应用 → 顶部「设置」→ 填两项，然后保存：

配置填什么不填会怎样
① Dify 工作流Dify API Key（app- 开头）与工作流地址问诊不会走知识库；应用会自动用 DeepSeek 直连兜底，正文照出，但不含知识库内容
② 编排判定模型DeepSeek API Key（sk- 开头）工具编排不可用（患者识别/落盘/复诊对比不会自动触发），问诊正文仍可进行

怎么确认填对了：保存后重新打开「设置」，应显示脱敏值（如 app-****abcd）与「当前问诊路线：Dify 工作流（路线 A）」。 启动日志里也会出现 已加载垂域 Pack：… tcm v… 与 模型: dify-chatflow。

换密钥 / 共用一台电脑：直接覆盖即可（留空 = 不修改）。密钥只落在本机数据目录的 credentials.json（权限 600），换人用时换一把即可，互不影响。

③问诊

  1. 左侧填患者资料与病历：主诉、现病史是必填（缺了不会落盘 —— 半份病历会被下次复诊当成基线，比没有更危险）。舌象、脉象、既往史等可选。
  2. 点「直接问诊（合成并发送）」—— 一键把表单合成消息发出。想先改措辞就用「合成到输入框」。
  3. 右侧上方是工具执行区（患者识别、建号、落盘、复诊对比），下方是问诊正文。
  4. 复诊时同样填表发送即可：系统按姓名 + 出生年 + 性别定位老患者，同名多命中会把候选交给你确认，不会自己挑一个。

问诊正文一定会有：若 Dify 工作流不可用（网络/限流/工作流自身报错），应用会自动切换 DeepSeek 直连出正文，并在日志里写明切换原因（本次不含知识库）。不会让你对着一个空回复。

它不是诊断工具：本应用是知识工作助手，不输出诊疗建议、不下诊断；缺项绝不编造；判断权始终归属执业医师。

④患者名册与随访

  • 顶部「患者」→ 名册（按超期优先排列）、点开看历次病历与逐次变化（消失/减轻/无变化/加重）。
  • 顶部提醒条：有超期或临期患者时出现，点「查看 →」直达；可开桌面提醒（需授权）。
  • 默认超期阈值 14 天、临期提前 3 天。

⑤更新与反馈

  • 检查更新：菜单「帮助 → 检查更新」。发现新版本会提示并给出下载入口。
  • 使用帮助：就是本页（菜单「帮助 → 使用帮助」）。
  • 问题反馈：社区论坛（菜单「帮助 → 问题反馈」）。
  • 官网：下载页。

反馈时请附上：版本号（菜单「帮助 → 关于」）、操作系统、以及复现步骤。 需要贴日志时请先确认其中没有密钥 —— 内核日志与诊断包已自动掩码 sk-/app-/dataset- 等凭据。

常见问题

问诊回复很短或没有内容？

先看应用日志里有没有「已自动切换 DeepSeek 直连」这类行 —— 有的话是 Dify 那一跳出了问题（日志会写明原因），把该行贴到论坛即可。

提示「未配置数据目录」？

数据目录没解析出来。正常安装不会出现；若出现，检查是否设过 MINGDAO_HOME，或在 ~/.mingdao-tcm-desktop.json 里指定 {"home":"…"}。

复诊被当成首诊？

说明上一次的病历没落盘（例如发送时缺「主诉/现病史」）。到「患者」页确认名册里有没有这位患者。

密钥会随日志泄漏吗？

不会：审计日志、诊断包与错误信息都经过统一脱敏（sk-、app-、dataset-、Bearer、URL 内嵌凭据等），掩码保留前缀便于排查「配了哪一类」。
